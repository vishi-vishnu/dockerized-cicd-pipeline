This page is the app that the pipeline ships. Every push to main is tested, built into a Docker image, scanned, pushed to Docker Hub and deployed to AWS EC2. If the new version is unhealthy, the server rolls back on its own.

How a change gets here

  1. LintESLint, TypeScript checks
  2. TestVitest, 80% coverage gate
  3. BuildMulti-stage Docker image
  4. ScanTrivy blocks critical CVEs
  5. PushDocker Hub, tag = commit SHA
  6. DeploySSH to EC2, health check
  7. VerifyRollback if unhealthy
